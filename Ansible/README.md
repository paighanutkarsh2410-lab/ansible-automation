# Ansible Automation

This repository contains Ansible playbooks created while learning infrastructure automation and Linux administration.

## Playbooks Included

- Apache Installation
- Nginx Installation
- User Management
- LVM Configuration
- Filesystem Mounting
- Firewalld Configuration
- SELinux Management
- Package Updates
- Docker Installation
- Service Management
- Cron Job Configuration
- Static Website Deployment
- Host Connectivity Check
- Server Reboot

These playbooks are intended for learning and demonstration purposes.
